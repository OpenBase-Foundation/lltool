# LLtool

Leerlingtool is een SaaS- applicatie die is gemaakt om makkelijk fotoboeken van cohorts te maken. Het is gratis voor universiteiten, en scholen.
Wil je leerlingtool gebruiken als bedrijf, of wil je het (white- label) resellen? Dan heb je een commerciele licentie nodig. Neem dan contact op via lltool@overmans.nl.
